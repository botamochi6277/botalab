## Commands

- `npm run dev` — Vite dev server
- `npm run build` — `tsc && vite build` (type-check, then bundle to `dist/`)
- `npm run lint` — ESLint, `--max-warnings 0`
- `npm run preview` — serve the built `dist/`
- There is no test suite.
- Refresh ProtoPedia data: `node scripts/fetch_prototype_v2.js <userName> <api_key>` (options: `-o` output JSON, `--img_dir`). Writes `src/assets/prototypes_v2.json` and downloads images into `public/prototypes/` (create that directory first; it is gitignored).

## Architecture

BotaLab is a static single-page maker profile site (React 19 + MUI + Vite, TypeScript), deployed to GitHub Pages at botalab.tech. There is no backend: all content comes from JSON files imported at build time from `src/assets/`.

Data sources:

- `prototypes_v2.json` — generated by `scripts/fetch_prototype_v2.js` from the ProtoPedia v2 API. It is also regenerated in CI, so local edits get overwritten. The older `prototypes.json` and `fetch_prototype.js` (v1 API) are legacy, and the app no longer imports them.
- `exhibitions.json` — hand-maintained exhibition list. Each entry links to ProtoPedia works through `prototype_ids`. Icons are referenced by filename (e.g. `nt_generic.svg`).
- `profile.json` — team/profile info.

`App.tsx` loads the profile and prototype data and lays out tabs (`MyTabs`): the ProtoPedia list (`ProtoPediaList` → `PrototypeCard`), `ExhibitionTimeline`, `StatsTab` (MUI X charts) and `NetworkTab` (Cytoscape graph of relations). `ExhibitionTimeline` and `StatsTab` import `exhibitions.json` directly. Shared types are in `src/product.d.ts`. The theme is in `src/theme.tsx`.

Conceptual data model (project / work / tool / material / exhibition / competition) is described in the README's ER diagram. ProtoPedia only covers works, so the other entities are maintained locally.

> [!NOTE] this repository is being changed data source architecture. Prototypes data fetched from protopedia-api is insufficient to describe projects, works, and developing activities. The prototypes data will be split to projects and works.

## Deployment

`.github/workflows/pages.yml` runs on push to `main` and nightly (17:00 UTC). It fetches prototypes using the repo variable `PROTOPEDIA_USERNAME` and secret `PROTOPEDIA_API_KEY`, runs `npm run build`, and publishes `dist/`. `vite.config.ts` sets `base` to `"botalab"` when `GITHUB_PAGES` is set and `./` otherwise.
